# CLAUDE.md

## Project Overview

Google Apps Script development template using TypeScript + clasp + Jest + esbuild + Docker.
Copy this template to create new GAS projects.

> ⚠️ **直接編集禁止**: This template (and any project derived from it) is managed via GitHub. Do NOT edit code in the Apps Script Web editor — changes will be overwritten by the next `npm run push`. Always edit under `src/` locally and deploy via `npm run push`.
>
> **For template users**: When cloning this repo to start a new project, see the "テンプレートとして使う場合の書き換え箇所" section in README.md for the list of files to rewrite (`package.json`, `README.md`, `src/config/settings.ts`, `.clasp.json`, etc.).

## Commands

```bash
npm run build           # src/*.ts -> dist/Code.js (esbuild)
npm run push            # build + clasp push
npm run deploy          # build + push + clasp deploy
npm test                # Jest tests
npm run test:coverage   # 70% threshold
npm run docker:dev      # Containerized dev (file watch)
```

Other scripts: `watch`, `open`, `test:watch`, `docker:build`, `docker:test`, `docker:shell`.

## Architecture

Build pipeline: `src/*.ts -> esbuild (esbuild-gas-plugin) -> dist/Code.js -> clasp push -> GAS`

```
src/
  main.ts              # Entry point - GAS global function registration
  config/settings.ts   # App config + PropertiesService helpers
  lib/                 # errors, logger, secrets, db, long-running, utils
  handlers/            # http (doGet/doPost), scheduled triggers
  types/global.d.ts    # AppConfig, LogLevel, global
__tests__/
  setup.ts             # Loads GAS mocks, TZ=Asia/Tokyo
  mocks/gas-mocks.ts   # GAS API mock implementations
  unit/                # Mirrors src/ structure
dist/, coverage/       # auto-generated - do NOT edit
```

## Available Skills

`.claude/skills/` 配下に以下が登録済み。description に従って自動発火する。

| Skill | 発火条件 |
|---|---|
| `gas-best-practices` | GAS API（SpreadsheetApp, Jdbc, ScriptApp 等）を含む TS を書く・読む・レビューする時 |
| `typescript-best-practices` | TypeScript / JavaScript ファイル全般 |
| `javascript-typescript-jest` | Jest テストを書く時 |

外部スキルは `npx skills add <owner/repo@skill> -a claude-code -a codex -y` で追加可能。`skills-lock.json` がコミット対象。

## Code Conventions

詳細は @.claude/rules/gas-source.md および @.claude/rules/testing.md を参照。

要点:
- TypeScript strict mode, ES2019 target, Timezone: Asia/Tokyo
- コメント・ドキュメントは日本語
- Test coverage threshold: 70%
- GAS callable functions は `global.foo = foo` で登録（詳細は gas-source.md）
- 設定値は PropertiesService（環境変数ではない）

## Key Config Files

| File | Purpose |
|------|---------|
| `appsscript.json` | GAS runtime settings (V8, Asia/Tokyo, OAuth scopes) |
| `.clasp.json` | clasp connection (scriptId) - DO NOT commit |
| `esbuild.config.js` | Build config (entry: src/main.ts, out: dist/Code.js) |
| `jest.config.js` | Test config (ts-jest, 70% threshold, setup file) |
| `tsconfig.json` | TypeScript config (strict, ES2019, ESNext modules) |

## Do NOT

- Edit files in `dist/` (auto-generated by esbuild)
- Edit files in `coverage/` (auto-generated by Jest)
- Commit `.clasp.json` or `.clasprc.json` (contain credentials)
- Use environment variables for GAS runtime config (use PropertiesService)
- Modify `esbuild.config.js` unless necessary
